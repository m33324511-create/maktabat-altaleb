مكتبة الطالب V4 - GitHub Pages

المميزات:
- صفحة رئيسية حديثة ومتجاوبة للموبايل والكمبيوتر.
- مكتبة تبدأ فارغة.
- بحث عن الكتب وتصنيفها.
- دعم ملفات PDF.
- فتح PDF داخل الموقع عبر عارض مدمج، مع زر تحميل.
- وضع ليلي/نهاري مع حفظ الاختيار.
- لا يوجد رفع ملفات للزوار.
- حقوق الإنشاء: Moaaz Amer.

إضافة كتاب:
1) ضع ملف PDF داخل مجلد books.
2) اختياريًا ضع صورة الغلاف داخل covers.
3) افتح index.html وابحث عن const books.
4) أضف عنصرًا مثل:
{title:"اسم الكتاب",subject:"رياضيات",description:"وصف الكتاب",file:"books/book.pdf",cover:"covers/book.jpg"}

النشر على GitHub Pages:
- ارفع محتويات هذا المجلد إلى مستودع GitHub.
- من Settings > Pages اختر النشر من الفرع الرئيسي (main) ومن المجلد الجذر (root).


مساحات الإعلانات (V4):
- توجد 3 مساحات إعلانية جاهزة ومخفية حاليًا: أعلى المكتبة، بين المحتوى، وأسفل الصفحة.
- لا تظهر أي إعلانات الآن. عند اختيار مزود إعلانات مستقبلًا، يمكن وضع كود الإعلان داخل العناصر: ad-top و ad-between و ad-footer، ثم إزالة display:none من المساحة المطلوبة.
- لا تضع أكواد إعلانية حقيقية قبل التأكد من شروط مزود الإعلانات وحسابك.
