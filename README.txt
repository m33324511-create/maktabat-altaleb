مكتبة الطالب - النسخة الجاهزة للرفع

هذه النسخة متصلة بمشروع Supabase الخاص بالموقع.

ما تم تجهيزه:
- تحميل الكتب الموجودة في Supabase وعرضها لكل الزوار.
- زر إضافة كتاب محمي بكلمة مرور.
- رفع PDF إلى Supabase Storage.
- حفظ بيانات الكتاب في جدول books.
- الكتاب الجديد يظهر مباشرة بعد نجاح الرفع.
- كلمة مرور الرفع ليست موجودة داخل كود الموقع.

طريقة الرفع:
- ارفع محتويات هذا المجلد كما هي إلى استضافة الموقع أو GitHub Pages.
- يجب أن يكون index.html في المجلد الرئيسي للموقع.

ملاحظة أمنية:
- لا تضف SUPABASE_SERVICE_ROLE_KEY أو كلمة مرور الرفع إلى ملفات الموقع.
